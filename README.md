# Dino
3D website for google dino game made by three.js having three lanes and cactus as obstecales appears randomly in the lanes


![screenshot](https://cdn.hackclub.com/01a016ef-143a-7230-ab7d-30da707bf9d3/screenshot_2026-08-12_172405.png)

Demo URL : [](https://mohammed-assem.github.io/Dino/)

# Features
Three-lane with left/right arrow controls to move the dino between lanes.
3D dino and cactus models loaded from a GLB asset.
Cacti spawn randomly in different lanes and move toward the player.
Score increases continuously while the player survives.
